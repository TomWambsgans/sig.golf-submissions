# Compact SPHINCS candidate — work in progress

This branch contains a proposed submission in `submission/`. It is **not ready for a PR**: `SigGolf.Challenge.certificate` has not been proved. The values in `claim.json` are targets, not certified results: S = W = 11,324 bytes, C = 1,000,000 cycles, and S × C = 11,324,000,000. The cycle target is deliberately loose while the certificate is completed.

## Proved

- The exact keygen image returns the intended 16-byte public key and masked, authenticated cache for every secret key and random oracle. Its full trace, output bytes, 92,369,576-cycle termination, and keygen compression moment are proved.
- The exact expand image copies every signature byte into the witness. It terminates in 8,500 cycles, makes no hash calls, and meets its compression moment.
- The sign image loads and checks the masked cache. Its nonce and 24-tree FORS block has an exact trace and byte-for-byte agreement with the abstract scheme. The five lower WOTS layers have proved 52-chain endpoints and abstract leaf values. The full lower-layer authentication path is emitted byte-for-byte as the abstract `treePath`. The signer also has an exact 496-instruction digit-extraction trace, including every digit byte and checksum. The checksum branches and retry-counter control are proved. Its full retry loop and WOTS signature-chain proofs remain open.
- The verify image has exact FORS and lower-layer WOTS traces and byte semantics. WOTS chain and 52-chain recovery accept any aligned signature source below scratch memory and produce an exact verifier trace. Upper-layer digit decoding, setup, and semantic 52-chain recovery now compose into one bounded trace from the original witness to all WOTS endpoints at each of the five relocated blocks. The decoder and setup preserve the witness source bytes and public-key prefix. The XMSS node round and full path digest/root have exact traces, with path cost at most 141 cycles per node. Each completed root becomes the next layer's WOTS message byte-for-byte, and the repeated instruction blocks match. The complete WOTS/leaf block has a bounded, arbitrary-witness trace that relocates across upper layers. Composing the recovered WOTS endpoints with the leaf and XMSS path, six-layer composition, and the claimed total cycle bound remain open. Commitment mismatches are proved to reject and terminate below the universal cycle limit.
- The inherited abstract SPHINCS security and completeness proofs build with only standard Lean axioms. A concrete altered-cache MAC first-hit bound and a finite lazy-oracle model for the full adaptive interaction are proved. The exact keygen cache has a joint law with a fresh dynamic MAC answer, and this law extends through the sampled secret key and organizer interaction. The stopped reference game has an exact lazy-oracle law for the within-budget winning event; its charged queries are bounded on that event. The numerical 128-to-127-bit margin for cache and seed bad events is proved. On budget-good full-certificate runs, the joint game now proves the required bank contact without a support-wide query bound. The terminal creation-mass payoff also has an event-local bound. The budget-stopped bank potential, contact probabilities, and coupling to the concrete attacker result remain open.

The submission passes the independent source-admission check. Lean axiom guards on completed modules report only `propext`, `Classical.choice`, and `Quot.sound`.
