# Compact SPHINCS candidate — work in progress

This branch holds the proposed submission in `submission/`, based on the fork’s `beta` branch. It is not ready for a PR: `SigGolf.Challenge.certificate` is still missing. The published `claim.json` numbers are targets, not certified results.

The scheme uses 11,324-byte signatures and witnesses, a 16-byte public-key commitment, and a proposed 171,399-cycle verification bound. The abstract Lean security proof and the exact expand-image proof build. The verifier proof covers its first commitment hash and comparison, proves that the next hash input contains the submitted message word for word, and proves that the two subsequent 20-byte copy blocks preserve their source words. The 20-byte copied fields and 32-byte message are now proved together in one verifier state after the message-copy loop. The second HASH header, public-parameter copy, and six-register setup are certified through the instruction immediately before its ECALL. The public-parameter words at the second HASH input are proved equal to the witness words, and the trace from the first hash answer to the second HASH call is certified. The second HASH ECALL is proved to issue the exact message-digest query and charge 16 cycles for two compressions, conditional on its full 112-byte buffer invariant. The exact trace now relates the second HASH buffer’s message and three witness fields to the submitted bytes; the loaded execution is proved to preserve four zero scratch slots, so its second HASH header bytes are exact; the loaded trace now proves the full 112-byte second HASH query matches the abstract message-digest input. For an honestly serialized abstract signature, Lean also proves that its root, parameter, and randomizer fields satisfy this query invariant. Lean also proves the second HASH answer bytes and that their overlapping-byte FORS leaf extraction equals the abstract digest definition. The eleven instructions after that HASH answer are certified to produce the abstract 34-bit hypertree index and store it in both verifier index cells. The 24 repeated selector blocks are certified against the exact verifier image and proved to store the corresponding abstract FORS selectors. The extra digest selector is proved to take the acceptance branch precisely for admissible digests. For an honestly serialized abstract signature, the loaded witness prefix is proved unchanged through the second HASH call. The first FORS HASH input is proved equal to the abstract scheme’s first FORS-leaf oracle query. All 24 FORS secrets and authentication paths are proved to remain in the loaded witness through that HASH setup and its answer write. The next exact HASH step and fourteen-instruction result copy are certified; the copied 20-byte running root equals the abstract truncated oracle answer, while all witness openings remain intact. The four-instruction FORS-level initializer is certified too, giving an exact loop-entry state with level one, the same root, and the intact witness. The first authentication level now has a certified selector, both branch traces, and exact byte-level parent-hash inputs in either orientation. The first parent HASH header, parameter copy, register setup, ECALL site, and two-compression charge are certified. The parent tag, level position, tree, and node-index bytes now match the abstract parent-hash header. A conditional theorem now matches the full 80-byte parent HASH buffer to the abstract FORS parent query. For the first parent level, those encoded-child and public-parameter hypotheses are now connected to the prior verifier state and its running root and path sibling. Generalizing across later FORS levels and trees, and the remaining hypertree verifier path, are open. Full keygen/sign/verify correspondence, resource bounds, and the reduction for the committed public key and adversarial cache remain open.

The branch contains only the import closure needed by the current candidate, under the verifier’s file and source-size ceilings. Once the certificate builds and the verifier accepts it, this branch can be opened as an ordinary PR against `leanEthereum/sig.golf-submissions:beta`.
