# Compact SPHINCS candidate — work in progress

This branch contains a proposed submission in `submission/`. It is **not ready for a PR**: `SigGolf.Challenge.certificate` has not been proved. The values in `claim.json` are targets, not certified results: S = W = 11,324 bytes, C = 1,000,000 cycles, and S × C = 11,324,000,000. The cycle target is deliberately loose while the certificate is completed.

## Proved

- The exact keygen image returns the intended 16-byte public key and masked, authenticated cache for every secret key and random oracle. Its full trace, output bytes, 92,369,576-cycle termination, and keygen compression moment are proved.
- The exact expand image copies every signature byte into the witness. It terminates in 8,500 cycles, makes no hash calls, and meets its compression moment.
- The sign image loads and checks the masked cache. Its nonce and 24-tree FORS block has an exact trace and byte-for-byte agreement with the abstract scheme. The five lower WOTS layers have proved 52-chain endpoints and abstract leaf values. The full lower-layer authentication path is emitted byte-for-byte as the abstract `treePath`. The signer also has an exact 496-instruction digit-extraction trace, including every digit byte and checksum. From encoding entry, n failed checksum attempts followed by a successful one reach WOTS chain signing in exactly 594n + 590 instructions, 601n + 597 cycles, and n + 1 HASH calls. Every accepted encoding leaves its decoded digits in the cells used by chain signing; when the HASH answer bytes encode the abstract digest, those digits equal the abstract WOTS encoding byte-for-byte. WOTS signature-chain serialization and full signer refinement remain open.
- The verify image has exact FORS and lower-layer WOTS traces and byte semantics. WOTS chain and 52-chain recovery accept any aligned signature source below scratch memory and produce an exact verifier trace. Upper-layer digit decoding, setup, semantic 52-chain recovery, endpoint copy, and leaf HASH compose into one bounded trace at each of the five relocated blocks. The resulting XMSS starting-root bytes equal the abstract leaf digest. Leaf copy and HASH preserve the witness and XMSS input controls, and XMSS initialization sets the path level and copies the leaf index to the path-bit cell. The decoder and setup preserve witness source bytes and the public-key prefix; the 52-chain proof carries layer, tree, leaf, path-bit, pointer, and witness values forward. For one upper layer, the decoded leaf and `pathState` compose to the abstract XMSS root and to any following execution with exact resource charges; path cost is at most 141 cycles per node. The wire encoding proves every XMSS path and WOTS chain byte occupies its verifier slot after loading; a low-memory-preserving prefix also retains the chain bytes and public-key prefix. The upper-layer theorem and its 43-cycle handoff preserve low-memory witness bytes, carry later paths, and put the completed XMSS root into the next WOTS message. The repeated instruction blocks match. Connecting the earlier verifier prefix to these layer invariants, discharging the next decoder's preconditions, composing all six layers, and proving the claimed total cycle bound remain open. Commitment mismatches are proved to reject and terminate below the universal cycle limit.
- The inherited abstract SPHINCS security and completeness proofs build with only standard Lean axioms. A concrete altered-cache MAC first-hit bound and a finite lazy-oracle model for the full adaptive interaction are proved. The exact keygen cache has a joint law with a fresh dynamic MAC answer, and this law extends through the sampled secret key and organizer interaction. The stopped reference game has an exact lazy-oracle law for the within-budget winning event; its charged queries are bounded on that event. The numerical 128-to-127-bit margin for cache and seed bad events is proved. On budget-good full-certificate runs, the joint game proves the required bank contact without a support-wide query bound. The adaptive monitor's creation mass stays within Q even if its last signing call overshoots the true-cost budget. The weighted, independent proposal-word law then bounds the actual budgeted full-certificate event by Q times `fullCertificateTotalRate` plus an isolated exceptional probability. The exceptional event splits into cache-hit and proposal-prefix events, and its cache-hit probability has a Q-proportional bound for computations with a hard query cap. A pointwise reachable-state price cannot give the needed 127-bit rate; the proof retains the weighted law. A query-level stopped coupling is still needed to transfer the hard-cap cache bound to the actual game, whose signing calls are charged only after completion; coupling to the concrete attacker result also remains open.

The submission passes the independent source-admission check at 994 of 1000 allowed entries. Lean axiom guards on completed modules report only `propext`, `Classical.choice`, and `Quot.sound`.
