# Compact SPHINCS candidate — work in progress

This branch contains a proposed submission in `submission/`. It is **not ready for a PR**: `SigGolf.Challenge.certificate` has not been proved. The values in `claim.json` are targets, not certified results: S = W = 11,324 bytes, C = 1,000,000 cycles, and S × C = 11,324,000,000. The cycle target is deliberately loose while the certificate is completed.

## Proved

- The exact keygen image returns the intended 16-byte public key and masked, authenticated cache for every secret key and random oracle. Its full trace, output bytes, 92,369,576-cycle termination, and keygen compression moment are proved.
- The exact expand image copies every signature byte into the witness. It terminates in 8,500 cycles, makes no hash calls, and meets its compression moment.
- The sign image loads and checks the masked cache. Its nonce and 24-tree FORS block has an exact trace and byte-for-byte agreement with the abstract scheme. The five lower WOTS layers have proved 52-chain endpoints and abstract leaf values, and their authentication paths are emitted byte-for-byte as the abstract `treePath`. The real forest-to-bottom-WOTS trace carries the digest and index through the handoff and subtree path to the first encoding HASH; its query and result match the abstract tweakable hash. When that digest decodes, the concrete padding and 52-digit checksum checks pass. The signer also has an exact 496-instruction digit-extraction trace and a proved retry prefix: n failed checksum attempts followed by a successful one reach chain signing in exactly 594n + 590 instructions, 601n + 597 cycles, and n + 1 HASH calls. Accepted digit bytes match the abstract encoding. From the accepted encoding PC, an exact 55-instruction trace copies the original 32-byte secret key into the first WOTS derivation buffer. Proving the secret HASH, successful retries, WOTS signature-chain serialization, and full signer refinement remains open.
- The verify image has exact FORS and lower-layer WOTS traces and byte semantics. Upper-layer digit decoding, setup, 52-chain recovery, leaf HASH, and XMSS path recovery compose into a bounded trace at each of five relocated blocks; the recovered root equals the abstract root. The loaded witness places every XMSS path and WOTS chain byte at its verified address. A 43-cycle handoff preserves future witness bytes and puts the completed root into the next WOTS message. For the first upper layer, the exact 61-instruction, 68-cycle predecoder trace checks the signed counter, makes one HASH call, checks padding, and resets the digit sum, assuming an abstractly decodable HASH answer. Four concrete HASH buffer regions imply the abstract encoding query; the witness counter, public parameter bytes, and prior-root payload are carried through the pre-HASH execution. The remaining header and abstract-counter facts must connect the actual pre-HASH state to that query. The repeated instruction blocks match. Composing all six layers and proving the claimed total cycle bound remain open. Commitment mismatches are proved to reject and terminate below the universal cycle limit.
- The inherited abstract SPHINCS security and completeness proofs build with only standard Lean axioms. A concrete altered-cache MAC first-hit bound and a finite lazy-oracle model for the full adaptive interaction are proved. The exact keygen cache has a joint law with a fresh dynamic MAC answer, and this law extends through the sampled secret key and organizer interaction. The stopped reference game has an exact lazy-oracle law for the within-budget winning event; its charged queries are bounded on that event. The numerical 128-to-127-bit margin for cache and seed bad events is proved. On budget-good full-certificate runs, the joint game proves the required bank contact without a support-wide query bound. The adaptive monitor's creation mass stays within Q even if its last signing call overshoots the true-cost budget. The weighted, independent proposal-word law then bounds the actual budgeted full-certificate event by Q times `fullCertificateTotalRate` plus an isolated exceptional probability. The exceptional event splits into cache-hit and proposal-prefix events, and its cache-hit probability has a Q-proportional bound for computations with a hard query cap. A pointwise reachable-state price cannot give the needed 127-bit rate; the proof retains the weighted law. The proof now couples one cache-monitor update and an arbitrary preceding history to a query-level stopped random-oracle run, preserving the final cache without assuming a hard cap on macro-charged signing. Composing this across the whole certificate game and coupling to the concrete attacker result remain open.

The submission passes the independent source-admission check at 994 of 1000 allowed entries. Lean axiom guards on completed modules report only `propext`, `Classical.choice`, and `Quot.sound`.
