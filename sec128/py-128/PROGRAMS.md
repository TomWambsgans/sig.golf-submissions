# SPHINCS-golf-128: RISC-V programs (128-bit study)

Scheme: `ref.py` (authoritative byte formats and query order); design and security argument:
`work/design/SEC128-STUDY.md`. Derived from py-opt8 (SPEC-v7, 127 bits). Generated by `gen.py`
(assembler `asm.py`, emulator `vm.py`); `test.py` runs the differential tests; `out/*.lst` are the
program listings (the Lean export of py-opt8 was not ported).

**Measured:** S = 6720, W = 6900, K = 131072 (cache buffer; 69,640 bytes used), honest verify
≤ 13,887 cycles (exactly 13,887 − #(digits equal to 7)), C = 13,887 + ⌈6900/256⌉ = **13,914**,
S × C = **93,502,080** (+26.2 % vs 74,113,492).

## Scheme summary (differences from SPEC-v7)

| item | 127-bit (py-opt8) | 128-bit (this) |
|---|---|---|
| node values (FORS leaves/nodes/roots, OTS leaves, tree nodes, roots hash, masks) | 128 bits | **129 bits**: `lo` = answer bytes 0..16, `b` = bit 0 of answer byte 16 |
| WOTS chain values / chain secrets | 128 bits | **136 bits**: answer bytes 0..17 (lo + whole byte 16 "hi") |
| FORS secrets | 128 (paired prf) | **129**: lo from paired prf, b from 4 extra prf answers per tree |
| WOTS secrets | paired prf (21 queries) | prf **stream** of 23 answers, secret i = bytes [17i, 17i+17) |
| chains / code | 42 digits + 2 pinned bits, T = 184 | **43 digits** (129 answer bits), **T = 195** |
| digest | rho_a = PRF(S, m, a), 3 compressions per trial, pin 10 bits | rho = PRF(S, m) once (129 bits), trial counter a in the digest tweak (1 compression per trial), **pin 11 bits** (174..184) |
| public key | root (128) | root.lo; verify also requires root.b = 0 (keygen grinds the **root salt sigma**, 8 bits, in the p field of the root query) |
| cache | tag, 4094 × 16 masked nodes | tag, 4094 × 16 masked lo, 4094 masked b bytes, 0^2, LE64 sigma (69,608-byte region, MAC 1089 blocks) |
| S / W | 6404 / 6404 | 6720 / 6900 |

## Oracle blocks (every query is one of these exact byte strings; zero padded to 64k)

Tweak `enc(t, lay, tau, p, j) = 1 | t | lay | tau>>32 | LE32 p | LE32 tau_lo | LE32 j` (16 bytes).

| tag | block | bytes |
|---|---|---|
| 0 WOTS prf | `enc(0, lay, tau, q, e) \| P \| S`, q = 0..22 | 64 |
| 1 chain step mu of chain i | `enc(1, lay, tau, (mu-1) \| i<<8, e) \| 0^31 \| v.hi \| v.lo` | 64 |
| 2 OTS leaf | `enc(2, lay, tau, 0, e) \| hi_0..hi_42 \| 0^21 \| lo_0..lo_42` | 768 (12 blocks) |
| 3 tree node | `enc(3, lay, tau, p, heap) \| L.b R.b 0^14 \| L.lo \| R.lo`, heap = 2^(h-lambda) + j, p = 0 (top root: p = sigma) | 64 |
| 4 encoding | `enc(4, lay, tau, 0, e) \| P \| M.lo \| LE64 M.b \| LE64 c` | 64 |
| 7 randomizer | `enc(7, 0, 0, 0, 0) \| P \| S \| m` | 128 |
| 8 FORS prf | pairs `enc(8, k, idx, 0, jp) \| P \| S` (jp < 512), extras `enc(8, k, idx, 1, q)` (q < 4) | 64 |
| 9 FORS leaf | `enc(9, k, idx, 0, j) \| P \| s.lo \| s.b \| 0^15` | 64 |
| 10 FORS node | as tag 3 with `enc(10, k, idx, 0, heap)`, h = 10 | 64 |
| 11 FORS roots | `enc(11, 0, idx, 0, 0) \| b_0..b_13 0^2 \| lo_0..lo_13` | 256 |
| 12 digest | `enc(12,0,0,0,0)[0:8] \| r \| rho.lo \| m`, r = rho.b \| a<<32 (LE64) | 64 |
| 13 mask | `enc(13, 0, 0, l, j) \| P \| S` | 64 |
| 14 MAC | `enc(14,0,0,0,0) \| P \| S \| region` (full 32-byte answer) | 69,696 (1089 blocks) |

Byte 1 is the tag and every tag has one fixed length, so the formats are domain separated; within
a tag all fields are copied injectively (the heap numbering is injective for 1 <= lambda <= h).
A verifier copies the sibling's `b` byte, a FORS secret's `b` byte, the chain `hi` bytes, `r`
and `sigma` from the witness without range checks (any value is a valid, merely non-honest
input); counters are range-checked (< 2^22).

Decoding: digest `N = LE(answer[0:24])`: idx = bits 0..33, u_k = bits 34+10k.. (k < 14),
admissible iff bits 174..184 are zero. Encoding: digits x_i = bits 3i.. of dword 0 (i < 21),
bits 3(i-21).. of dword 1 (21 <= i < 42), x_42 = answer byte 16 & 7; valid iff sum = 195 (bits
63, 127 and 131.. are ignored: the match entropy is exactly 129 bits).

## Signature and witness

Witness (verify input, 6900 bytes): `rho.lo | FORS k: s.lo, 10 path lo (176 each) | layers
lay = 0..4: 43 chain lo, h_lay path lo | chain hi bytes (43 per layer) | pad | r (LE64 at 6680) |
LE32 c_0..c_4 (6688) | LE32 sigma (6708) | FORS b bytes: s.b, 10 path b (11 per tree, 6712) |
layer path b bytes (6866..6900)`. Every 16-byte item is 8-aligned; every b / hi is a whole byte.

Signature (6720 bytes) = witness[0:6679] (all lo parts + the 215 hi bytes, byte-aligned) ||
41-byte bit field (LSB first): rho.b (1), a (20), sigma (8), c_0..c_4 (22 each), FORS b bits
(154), layer path b bits (34), 1 spare bit that must be 0. expand = copy + unpack (fails on a set
spare bit, so signatures and witnesses are in bijection); verify never unpacks bits.

## verify (loop-free; 14,530 main instructions + JALR dispatch tables, 75,360 words)

Same architecture as py-opt8 (two-track Merkle folds, JALR pair tables, value-last chain blocks,
constant registers for the chain tweak bytes). New or changed blocks (cycles on honest runs):

* **Digest** (28): `sd 0x0C01`, `ld/sd r`, rho.lo (4), hash, pin check `slli 7; srli 53; beq`.
* **FORS prefix** (+2): s.b byte `lbu; sb CB+48`.
* **Fold level** (22 = 14 instr + 8): V.b `lbu NB+48+16t; andi 1; sb NB+16+t` (V's answer byte 16;
  for t = 0 it lies in the sibling slot and is read before the copy), sibling lo (4), sibling b
  byte `lbu; sb NB+17-t`, heap index `srli; sw`, branch point (2), `addi a2; ecall`. Last level
  19 (heap 1), top root +2 (`lwu sigma; sw NB+4`). FORS root bit: `lbu RB2+48+16k; andi; sb
  RB2+16+k` (3). FORS runs in three tracked regions (5, 5, 4 trees; branch range), 2 merges.
* **Encoding** (precode): M.b `lbu EB+48; andi; sd EB+48`, counter `lwu; sd EB+56`; digit 42
  `lbu X25, EO+16; andi 7`; SWAR check (bits 63/127 excluded by the mask M1ODD = M1 without its
  top group, built once in x22 after layer 4's route; digit 42 added into lane 0) = 23 instr.
* **Chains**: sites = 10 pairs + single 20 per dword (single tables have 16 entries indexed by
  bits 60..63, so bit 63/127 needs no mask) + single 42 (`slli R, X25, 4; add R, R, B`).
  Head `ld v0; ld v1; lbu HI; [addi TP, i]; sb (TP | P_i | x0), CB+5; addi a2, CB+48; jalr` (6 for
  i <= 6: the byte i comes from P_i / x0, else 7). Entries (16 bytes): x < 7 `sd v0, CB+48;
  sd v1, CB+56; sb HI, CB+47; jal s_{x+1}`, x = 7 `sd, sd` into leaf slot i, `sb HI, LB+16+i;
  jal next`. Steps 1..6: `sb MU, 4(a0); ecall; lbu T, 64(a0); sb T, 47(a0)` (11: the answer's
  byte 16 is copied into the hi slot); step 7: `sb MU; addi a2, LB+80+16i; ecall; lbu; sb
  LB+16+i` (12). **Chain i costs 11 (7 - x_i) + 11 + [i >= 7] for x_i < 7 and 10 + [i >= 7] for
  x_i = 7**, so a layer costs at most 11 * 106 + 43 * 11 + 36 + preps (68) + LUIs.
* **Leaf**: a1 = 768 (12 blocks). **Compare** (12): lo vs pk, then `lbu FO+16; andi; bne`.

Per-phase cycles (honest max; old = py-opt8): prologue 16 (16), digest 28 (26), FORS incl.
roots and layer constants 3520 (2749), each layer 2018..2150 incl. its folds (1721..1821),
compare 12 (9). Hash cycles 6304 (788 compressions; old 6424 / 803), instructions 7583 (5123).

Why the cycle count is bounded: no loops; the data-dependent control flow is (a) track branches
(both directions cost 2), (b) the chain JALRs (cost above: every entry of a table has the same
cost except x = 7, which is one cycle cheaper), (c) reject branches to HALT stubs. A run reaching
the compare passed 5 encoding checks, so sum(7 - x) = 301 - 195 = 106 per layer; hence
cycles + #(x = 7) is the constant 13,887 on every run that reaches the compare, and every other
run is a prefix of such a run plus a HALT. `test.py` checks this constant on honest runs, on
full-length junk-witness runs (forced valid encodings, with and without digit 7) and on runs
covering every entry of every dispatch table.

## sign (2171 instructions), keygen (266), expand (1235)

* **keygen**: top tree (lay 0, tau 0, h 11) with `tree_build(keep)` into KT (levels 0..10, 32-byte
  entries: a HASH writes its 32-byte answer into the entry, lo = bytes 0..16, b = byte 16 & 1);
  root salt loop sigma = 0..255 (`NB+4 = sigma`, hash, stop when answer bit 128 = 0; fail after
  256); pk = root.lo; masks (l, j ascending): lo ^= mask.lo, b = (b ^ mask.b) & 1; sigma at
  region + 69600; MAC. 695,359 compressions + the salt trials (E = 2): E[2^(N/2^20)] = 1.584.
* **tree_build** (keygen and sign layers 4..1): per leaf the 23-query prf stream into SBUF, then
  for chains 0..42 the 17-byte secret slice into CB (hi at CB+47, lo at CB+48), 7 steps
  (`sw (mu-1) | i<<8, CB+4; hash; hi byte copy`), capture of the signed value, end into LB;
  leaf hash (768 bytes); levels with `node_hash` (lo copies, `lbu; andi 1; sb` of both b's).
* **sign**: MAC check (1089 blocks) → randomizer (2 blocks) → digest loop over a (1 block per
  trial, `sw a, DG+12`) → FORS (per tree: 4 extras, 512 pairs + 1024 leaves, levels, root lo/b into
  RB2) → roots hash → layers 4..1 (counter search with the 43-digit SWAR check; tree_build with
  capture) → layer 0 (counter search, prf stream, chains up to x_i, masked path from the cache,
  sigma) → pack (copy witness[0:6679], bit-pack 327 bits with a `putbits` subroutine).
  Everything is staged in witness format (STG) first. Deterministic 112,690 compressions (T = 195)
  + 1 per digest trial (p = 2^-11) + 1 per encoding trial (alpha = 2^-11.612, 5 searches):
  E[2^(K/2^17)] = **1.9943** analytic (1.9933 empirical over 400 signings). Worst case (last digest
  and counter trials everywhere): 838,818,192 cycles < 2^32.
* **expand**: copy witness[0:6679] from the signature, check the spare bit, unpack the bit field
  (`getbits` subroutine). No hashing.

## Tests

`python3 test.py [--keys N --msgs N --moment N --tables N --slow]`: keygen/sign/expand/verify vs
ref (outputs and exact query logs), tampered caches (tag, lo, b byte, pad, sigma: fail after
exactly the MAC query), junk cache tail, non-canonical signature (spare bit) rejected by expand,
witness corruptions (rho, r, FORS s/s.b/path/path.b, counters, sigma, chain lo/hi, path lo/b),
counters >= 2^22 rejected before hashing, wrong message / pk, non-admissible digest, random
witness, forced-encoding full-length runs, dispatch-table cover, sign moment, `--slow`:
worst-case keygen salt (sigma = 255) and sign (last digest / counter trials), salt, digest and
encoding exhaustion.

Last full run: `python3 test.py --keys 2 --msgs 3 --moment 400 --tables 256 --slow` → ALL PASSED
(C = 13,914, S = 6720; worst-case sign 838.8M cycles; digest / encoding / salt exhaustion fail
cleanly).

## Variant `SG128_FORSINT=1` (FORS internal nodes and roots at 128 bits)

`SG128_FORSINT=1 python3 test.py ...` builds and tests the variant of SEC128-STUDY.md §6.6: FORS
nodes of levels 1..10 and the FORS roots have b = 0 (not stored, not hashed: the fold at level 1
clears the b bytes with one `sw x0, NB+16`, levels 2..10 cost 17 cycles, no root-bit extraction),
the signature carries only s.b and the level-0 sibling bit per tree (S = 6705). Measured
C = 13,229 + 27 = 13,256, S × C = 88,881,480. Its security needs an extra proof component.
