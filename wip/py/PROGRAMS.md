# SPHINCS-golf RISC-V programs

Generated by `gen.py` (assembler `asm.py`, emulator `vm.py`, reference `ref.py`, tests `test.py`,
Lean export `export_lean.py` -> `out/Images.lean` + `out/*.lst` listings). Everything here refers to
the default witness mode **`perm`**; `copy` mode (witness = signature) is kept as an option
(`python3 gen.py copy`, `python3 test.py --mode copy`) and costs about 919 more verify cycles.

Conventions used throughout:
* `P = 0^128`. A tweak is 16 bytes: `word0 = 1 | t<<8 | lay<<16 | (tau>>32)<<24 | p<<32`,
  `word1 = (tau mod 2^32) | j<<32` (little-endian dwords at buffer+0 and buffer+8).
* Every hash input buffer has the layout `tweak(16) | P(16) | payload`. The P slot (+16..+32) is
  **never written** by any program, so it stays zero from the initial memory.
* HASH is `ECALL` with `t0 = x5 = 0`, `a0` = input, `a1` = length, `a2` = output. `x5` is 0 from the
  initial state and is only set (to 1) immediately before HALT. HALT = `addi t0,x0,1; addi a0,x0,c;
  ecall` (c = 0 success / 1 failure).
* Only real RV64I encodings are emitted: LUI, ADDI, XORI, ORI, ANDI, SLLI, SRLI, ADD, SUB, SLL, SRL,
  OR, AND, LD, LW, LWU, LBU, SD, SW, SB, BEQ, BNE, BLT, BGE, BLTU, BGEU, JAL, ECALL. No MUL/DIV, no
  JALR, no AUIPC. "nop" is `addi x0,x0,0` (decodes as ADDI). `asm.finish` decodes every word with
  the organizer's decoder (re-implemented in `vm.decode`) and checks it equals the intended
  instruction; a Lean check (`decide +kernel`) also confirmed that all words decode and that the
  submission is `Admissible`.
* No embedded data (`D = 0`, `data_base = 0x1000000`, `sp` is never used as a stack).

## Sizes, layout, witness format

| object | offset | bytes |
|---|---|---|
| message | `0x40` | 32 |
| secret key | `0x80` | 32 |
| public key | `0xA0` | 16 |
| cache | `0x44A0` | 131072 (unused: keygen leaves it zero, sign never reads it) |
| signature | `0x2650` | S = 7756 |
| witness | `0x800` | W = 7756 |

Signature (SPEC): `rho(16) | FORS kappa=0..13: (s, 10 siblings) (176 each) | layers lay=0..6:
(LE32 c, 42 chain values, h_lay siblings)`. Layer `lay` starts at `2480 + 756*lay`.

Witness (`perm`): the signature with the seven counters moved to the end, so every 16-byte item
is 8-aligned:
`rho | FORS (same as signature, 0..2480) | lay=0..6: 42 chain values, h_lay siblings (752 each,
layer 6: 736) | LE32 c_0 .. c_6 (at 7728)`. Chain value i of layer lay is at
`2480 + 752*lay + 16 i`, sibling l at `2480 + 752*lay + 672 + 16 l`, counter at `7728 + 4 lay`.
`ref.to_witness` / `ref.from_witness` are the (inverse) byte permutations; expand is exactly
`to_witness`.

### Scratch buffers (all fixed addresses)

| name | addr | size | content |
|---|---|---|---|
| DB | `0x000` | 128 | digest input `tw_msg | P | rho | 0^16 | m | 0^32`; **m is the message buffer itself** (0x40); 0x30..0x40 and 0x60..0x80 are never written except 0x30..0x40 re-zeroed by sign |
| CB | `0x0C0` | 64 | chain / FORS-leaf input `tw | P | value | 0^16` (pad 0xF0..0x100 is zero at every chain start) |
| EB | `0x100` | 64 | encoding input `tw | P | M | LE32 c | 0^12`; M is written by the previous hash (a2 = EB+32) |
| EO | `0x140` | 32 | encoding output |
| DO | `0x160` | 32 | digest output |
| FO | `0x180` | 32 | verify: final root |
| NB | `0x1C0` | 64 (+16 junk to 0x210) | node input `tw | P | L | R`; NB+32 = 0x1E0 has bit 4 clear, so the right slot is `left ^ 16` |
| RB2 | `0x220` | 256 (+16 junk) | FORS roots input `tw | P | root_0..root_13` |
| LB | `0x340` | 704 (+16 junk to 0x610) | OTS leaf input `tw | P | pk_0..pk_41` |
| RB | `0x620` | 128 | sign: randomizer input `tw_rnd(a) | P | S | m | 0^32` |
| PB | `0x6A0` | 64 | sign/keygen: prf input `tw | P | S` (FORS prf and WOTS prf) |
| DIG | `0x6E0` | 42 | sign: digits x_0..x_41 of the current layer (bytes) |
| US | `0x710` | 112 | sign: u_0..u_13 (dwords) |
| FA | `0x30000` | 1025*16 | sign: FORS tree array (slot 1024 = junk) |
| TA | `0x34100` | 33*16 | sign/keygen: hypertree tree array (slot 32 = junk) |

"Junk" regions receive the upper 16 bytes of a 32-byte hash answer whose useful half lands in the
last slot of the buffer; they are never read.

All buffers below 0x800 are addressed as `imm(x0)`.

## Query order (unchanged from the task statement; ref.py is identical query for query)

* **keygen**: tree (lay 0, tau 0, h 5): leaves e = 0..31 in order; per leaf, for chains i = 0..41:
  `prf = Th(tw(0,0,0,i,e), S)` then 7 steps `Th(tw(1,0,0,8i+mu-1,e), .)`, mu = 1..7; then the leaf
  hash `Th(tw(2,0,0,0,e), pk_0..pk_41)`; then levels lambda = 1..5, nodes j left to right
  `Th(tw(3,0,0,lambda,j), X_{2j} | X_{2j+1})`.
* **sign**: (1) for a = 0..2^20-1: `rho = Th(tw(7,0,0,a,0), S|m)`, `Digest = H(tw_msg|P|rho|0^16|m)`,
  stop at the first admissible one. (2) for kappa = 0..13: leaves j = 0..1023 (`Th(tw(8,kappa,idx,0,j),S)`,
  `Th(tw(9,kappa,idx,0,j), s)`), then levels 1..10 left to right (`tw(10,kappa,idx,lambda,j)`); then
  `Th(tw(11,0,idx,0,0), roots)`. (3) for lay = 6..0: counters c = 0..2^20-1 of
  `Th(tw(4,lay,tau,0,e), M|LE32 c)` until one decodes; then tree (lay, tau) exactly as keygen's.
* **expand**: no queries.
* **verify**: first the counter range check (no queries): reject if any `c_lay >= 2^20`. Then
  exactly `Concrete.verify` order: digest; (reject if `u_14 != 0`); for kappa = 0..13: leaf hash then
  10 folds; roots; for lay = 6..0: encoding (reject if bits 63/127 set or digit sum != 170), chains
  i = 0..41 steps mu = x_i+1..7, leaf, h folds; compare with pk.

## verify (loop-free straight-line code with forward branches, 20046 instructions)

Registers (constant after the prologue unless noted):

| reg | role |
|---|---|
| x5 (t0) | 0 (hash selector) |
| a0/a1/a2 | hash input / length / output |
| x1, x2 | v0, v1: 16-byte copy registers |
| x3 | T: temp; **during a chain: the digit in bits 61..63** (`slli T, Dq, 61-3r`) |
| x4 | TP: tweak-field temp |
| x6,x7,x8,x9,x13,x14,x15 | thresholds `k << 61`, k = 1..7 |
| x16, x17 | D0, D1: digest words (w0, w1 during FORS; d0, d1 of the current encoding during a layer) |
| x18..x21 | witness bases `WIT + 2048k`, k = 0..3 (every witness access is one load with an immediate) |
| x22 | idx (34 bits) |
| x23, x24 | U = current leaf index (u_kappa or e_lay), U16 = U << 4 |
| x25 | w2 during FORS; enc-check temp later |
| x26, x27 | M1 = 3-bit fields at 6k, M2 = 6-bit fields at 12k (digit-sum masks) |
| x28 | temp |
| x29 | FW = `1 | 9<<8 | kappa<<16 | (idx>>32)<<24` (FORS leaf word, +1<<16 per tree) |
| x30 | TAU of the current layer |
| x31 | 1<<16 during FORS; `tau | e<<32` during a layer |

Blocks (labels in `out/verify.lst` / `verifyLabels`):

1. `start`: prologue constants (36 instr).
2. `counters`: `OR` of the three counter dwords and the last counter word, `OR` with
   `0x000FFFFF000FFFFF`, `BNE -> reject` (every counter < 2^20).
3. `digest`: store `tw_msg` at DB, copy rho from the witness to DB+32, hash DB (128 bytes) -> DO;
   admissibility `(w2 << 8) >> 54 == 0` (bits 174..183); `reject:` HALT(1) sits inline here;
   `admissible:` idx = `(w0 << 30) >> 30`.
4. FORS setup: `SW idx` at CB+8, NB+8, RB2+8 (low 32 bits = tree field); FW; a1 = 64.
5. `fors_k`, k = 0..13 (unrolled): extract u_k (2..4 instr); `SW FW,CB`; `SW U,CB+12`; copy s_k to
   CB+32; a2 = `NB+32 + 16*(u&1)`; hash CB -> the leaf lands in its slot; `SW FW+0x100, NB`; then 10
   fold levels; `FW += 1<<16`.
   **Fold level lambda** (shared generator `fold_levels`, 12 instr + ECALL): invariant "V (current
   node) is at `a2 in {NB+32, NB+48}` and `a2 = NB+32 + 16*bit_lambda(E)`": sibling slot =
   `a2 ^ 16`, copy the witness sibling there; `SW lambda+1, NB+4`; `SW E>>(lambda+1), NB+12`; next
   a2 = `NB+32 + 16*bit_{lambda+1}(E)` (or the destination slot for the last level: RB2+32+16k for FORS,
   EB+32 for layers 6..1, FO for layer 0); ECALL.
6. `fors_roots`: word0 `1|11<<8|(idx>>32)<<24` at RB2, hash 256 bytes -> EB+32 (= M_6).
7. `layer_lay`, lay = 6..0 (unrolled, h = 4 for lay 6 else 5, s = sum_{j>lay} h_j):
   * route: `U = (idx >> s) & (2^h-1)`, `TAU = idx >> (s+h)`, x31 = `TAU | U<<32`.
   * encoding: EB word0 `0x401|lay<<16`, word1 x31, counter from the witness to EB+48, zero
     EB+52..64 (the previous hash wrote 16 junk bytes there), hash EB -> EO, D0/D1 = EO words,
     `enc_check` (23 instr: `(D0|D1) < 0 -> reject`; SWAR digit sum; `!= 170 -> reject`; the reject
     branches go to a stub `rej_l<lay>: jal reject` in the first side region of the layer).
   * chains: CB word0 low `0x101|lay<<16` (SW), CB word1 x31, a0 = CB, a2 = CB+32 (a1 = 64).
     Chains i = 0..41 in three groups of 14; after each group `jal l<lay>_after<g>` jumps over the
     group's **side region** (stub + side blocks of its 14 chains).
     **Chain block i** (`c<lay>_<i>_*`): `slli T, D_{i/21}, 61-3(i mod 21)`; copy witness value to
     CB+32; dispatch `bgeu T,T7,h7; bgeu T,T4,g4; bgeu T,T3,(p3); bgeu T,T2,(p2); bgeu T,T1,s2;`
     falls into `s1`. Step mu (labels `s1..s7`): `addi TP,x0,8i+mu-1; sw TP,4(a0); ecall;
     sd x0,48(a0); sd x0,56(a0)`; step 7 is `addi TP; sw; addi a2,x0,LB+32+16i; ecall; addi a2,a0,32`
     (the endpoint goes straight into leaf slot i; its junk half hits slot i+1, rewritten by chain
     i+1, or the LB junk area for i = 41). Side blocks: `g4: bgeu T,T6,(p6); bgeu T,T5,(p5); jal s5`;
     pad blocks `pX: nop* ; jal s_{X+1}`; `h7: sd v0/v1 -> LB+32+16i; nop; jal next`.
     Entry for digit x is `s_{x+1}`; the pads make **every chain cost exactly `10 + 12*(7-x)` cycles**.
     Invariant at chain start: CB pad = 0, a0 = CB, a1 = 64, a2 = CB+32, CB word1 = tau|e<<32.
   * leaf: LB tweak (`0x201|lay<<16`, x31), a0 = LB, a1 = 704, a2 = `NB+32+16*(e&1)`, hash.
   * fold: `SW 0x301|lay<<16, NB`, `SW TAU, NB+8`, a0 = NB, a1 = 64, h fold levels (block 5).
8. `compare`: FO vs pk (two dword compares, `BNE -> reject_final`), `accept:` HALT(0),
   `reject_final:` HALT(1).

Cost: honest verify = **18357 cycles** exactly, for every key/message/oracle (checked: constant over
all honest runs and over forced-encoding junk runs). Breakdown: prologue+counters+digest+admissible
96, FORS 3080 (14 x 220), roots 41, layer 6: 2145, layers 5..1: 2165 each, layer 0: 2161, compare+halt 9.
Chains per layer: `42*10 + 12*124 + 3` (group jumps) = 1911. Hashing is 1146 x 8 = 9168 cycles.
Why the bound holds on every input: the program has no backward branches; any run that reaches
`compare` passed every enc check, so each layer's digits sum to 170 and each chain costs
`10 + 12(7-x_i)`, i.e. the constant total; runs that reject earlier execute a prefix of that path
plus a 3-cycle HALT (the reject stubs sit on paths that are strictly shorter). Termination: <=
20046 + 1 steps.
Scored `C = 18357 + ceil(7756/256) = 18357 + 31 = 18388`, `S*C = 142,617,328`.

## sign (loops, 540 instructions)

Registers: x1/x2 v0/v1, x3 T, x4 TP, x5 = 0, x6 CNT (search counter a or c), x7 LIM = 2^20,
x8 KAP (FORS tree kappa; **LAY** in the layer phase), x9 J (FORS leaf j; **HH** = height in the
layer phase), x13 U (u_kappa; e_lay in the layer phase), x14 FW (`1|8<<8|(idx>>32)<<24`), x15 LAM (level),
x16 JJ (node index), x17 NCNT (loop bound: leaf count / node count), x18 SIGL (signature pointer: `SIG + 176 kappa`
in FORS, `SIG + 2480 + 756 lay` in the layer phase), x19 FAP (array base FA or TA), x20 EP (leaf),
x21 I (chain), x22 idx, x23 MU (step), x24 P (chain tweak position `8I + MU - 1`), x25 X (digit x_I),
x26/x27 M1/M2, x28/x29 temps, x30 TAU, x31 W1 (`tau|e<<32`).

Blocks / loops (one counter each; derived pointers move in lockstep):
1. setup: S -> PB+32, RB+32; m -> RB+64; RB word0 low `0x701`; DB word0 `0xC01`; constants.
2. `dig_loop` (counter CNT = a, bound LIM): `SW a, RB+4`; hash RB (128) -> DB+32 (rho; junk
   re-zeroed at DB+48..64); hash DB (128) -> DO; admissible -> `dig_ok`; else a++;
   `fail_digest` HALT(1) after 2^20 trials.
3. `dig_ok`: rho -> sig; idx; u_0..u_13 -> US.
4. `fors_loop` (KAP 0..13): U = US[KAP]; PB/CB word0 low; `fors_leaf_loop` (J 0..1023: prf -> CB+32,
   pad re-zeroed; if J == U copy the secret to `SIGL+16`; leaf hash -> FA+16J);
   `fors_level_loop` (LAM 1..10: capture FA[(U>>(LAM-1))^1] -> `SIGL+32+16(LAM-1)`; NB word0;
   NCNT >>= 1; `fors_node_loop` (JJ 0..NCNT-1, `node_hash`: FA[2JJ],FA[2JJ+1] -> NB+32..64, hash ->
   FA+16JJ)); root FA[0] -> RB2+32+16KAP; SIGL += 176.
5. roots hash -> EB+32.
6. `layer_loop` (LAY 6..0, SIGL -= 756 per iteration): s/h (branch on LAY == 6), route, EB tweak,
   `enc_loop` (CNT = c 0..2^20-1: `SW c, EB+48`; hash EB -> EO; `enc_check` -> `enc_next`/`enc_ok`;
   `fail_enc` HALT(1)); `enc_ok`: counter -> SIGL, digits -> DIG; **tree_build(capture)**; root TA[0]
   -> EB+32.
7. `success`: HALT(0).

**tree_build** (shared with keygen, labels `tb_*`): inputs LAY (x8), TAU (x30), HH (x9), capture
target U (x13), SIGL. `tb_leaf_loop` (EP 0..2^HH-1): word1 `TAU|EP<<32` -> PB+8, CB+8, LB+8;
`tb_chain_loop` (I 0..41): `SW I, PB+4`, prf hash PB -> CB+32, zero pad, `X = DIG[I]`, capture(MU=0);
`tb_step_loop` (MU 1..7): `SW P, CB+4`, hash CB -> CB+32, zero pad, P++, capture(MU); P++;
copy CB+32 -> LB+32+16I; leaf hash LB (704) -> TA+16EP. `tb_level_loop` (LAM 1..HH): capture
path sibling `TA[(U>>(LAM-1))^1] -> SIGL+676+16(LAM-1)` (4-byte copies: the signature layer may be
4-aligned only), NB word0 `0x301|LAY<<16|LAM<<32`, `SW TAU, NB+8`, NCNT >>= 1, `tb_node_loop`.
capture(MU): `if EP == U and MU == X: copy CB+32 -> SIGL+4+16I` (4-byte copies).

Costs (measured, honest): about 2.2-2.35M cycles, ~116-122k hash calls, 118k-128k compressions.
Compression moment: E[2^(K/2^17)] = 1.920 empirical over 200 signings (ref, identical counts),
1.916 analytic (deterministic 115,375 + 4 per digest trial with p = 2^-10 + 1 per encoding trial
with alpha = 2^-8.939, 7 searches). Sign adds no hashing beyond the spec.
Worst case (every search succeeds only at its last trial, every failing encoding trial fails at the
last test, i.e. the longest per-trial path): measured **336,648,645 cycles / 253,001,433 steps**
(< 2^32). Per-trial costs: digest trial 46 cycles, failing encoding trial <= 39 cycles, so the bound is
2^20 * (46 + 7*39) + ~2.4M = ~337M. Both exhaustion failures were run (digest: 48.2M cycles, a0 = 1;
layer-6 encoding: 41.7M cycles, a0 = 1).

## keygen (102 instructions)

S -> PB+32; LAY = 0, TAU = 0, HH = 5; tree_build without capture code; TA[0] -> pk. The cache is
never touched. Constant cost: **196,282 cycles, 10,815 hash calls, 11,135 compressions**.

## expand (167 instructions)

15 copy loops (`copy_*`, counter CNT, pointers SRC/DST = x6/x7, 4-byte LWU/SW): head (rho+FORS,
620 words), then for each layer the counter word (1) and the body (168 or 164 words). Constant
cost 11,711 cycles, no hashing. `copy` mode: one loop of 1939 words.
