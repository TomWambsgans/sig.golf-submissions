# Keygen refinement proof: notes (done)

Main results (`Main.lean`, axioms audited in `Axioms.lean`: only propext / Classical.choice /
Quot.sound):

* `keygen_run sk : submission.run .keygen sk =
    (fun pk => ⟨some (pk, 0), true, 196282, 10815, 11135⟩) <$> keygenRef sk`
* `keygen_run_counts sk : (fun r => (r.value, r.hashCalls, r.hashCompressions)) <$> submission.run .keygen sk =
    (fun p => (some (p.1, 0), p.2.1, p.2.2)) <$> Sign.countBoth (keygenRef sk)`
* `keygenRef_countBoth sk : Sign.countBoth (keygenRef sk) = (·, 10815, 11135) <$> keygenRef sk`,
  `keygenRef_counts` (countCalls / countBlocks)
* `keygen_runWith hash sk : submission.runWith hash .keygen sk =
    ⟨some (evalWithAnswerFn hash (keygenRef sk), 0), true, 196282, 10815, 11135⟩`

Keygen proves its own tree build (keygen's instance has no capture code).

Files
* `XSim.lean`: exact-cost refinement relation `XSim image s k c n b oa Q` (exactly `k` steps,
  `c` cycles, `n` calls, `b` compressions for every oracle; joint count via `Sign.countBoth`),
  combinators `pure_steps`, `bind`, `steps`, `query`, `hash16(_bind)`, `foldlM_range(')` with
  per-iteration costs (`sumTo`), `count_eq`, `countBoth_eq`, `run_eq`.
* `Blocks.lean` (generated by `gen_keygen.py`): segment table and `sym_block`s.
* `Spec.lean`: one lemma per block (steps, pc, registers, written doublewords, frame).
* `Words.lean`, `State.lean`: `SW` merges, input formats as numbers, `hashInput_eq_pad64`,
  `writeHash` memory, `ofNat` arithmetic.
* `Inv.lean`: `Base` invariant, `Frame`, `Vals` (16-byte values in an array).
* `Chain.lean`: chain step, chain (`chain_xsim`), leaf (`leaf_xsim`).
* `Tree.lean`: node (`node_xsim`), level (`level_xsim`), in place in the tree array.
* `Init.lean`, `Output.lean`, `Main.lean`: initial state (secret-key doublewords), pk / cache
  output buffers (cache: never written, `readBuffer_cache`), whole program.
* Shared byte lemmas live in `Expand/Mem.lean`.
