# `SigGolfCandidate.Ref`: byte-level reference spec of the SPHINCS-golf programs

A Lean copy of `work/py/ref.py`, query for query. It is meant as the target of the RISC-V
refinement proofs, and later as the thing to prove equivalent to the abstract scheme. The query
order is the one in `work/py/PROGRAMS.md` ("Query order"). Everything runs in
`OracleComp SigGolf.HashSpec` and can be executed (`evalWithAnswerFn` / `simulateQ`).

| file | content |
|---|---|
| `Basic.lean` | bytes, parameters, tweak, `pad64`, hash wrappers, all hash input formats, digest split, digit decoding |
| `Scheme.lean` | tree building, `keygenRef`, `signRef`, `expandRef`/`unexpandRef`, `verifyRef` |
| `Count.lean` | `countWith` / `countCalls` / `countBlocks` and their lemmas |
| `Lemmas.lean` | byte-conversion lemmas, lengths, `pad64_eq`, parameter tables, expand is a bijection |
| `Test.lean`, `Vectors.lean` | `#guard` checks against `ref.py` with a toy oracle (vectors generated by `tools/ref_vectors.py`) |
| `Axioms.lean` | axiom audit (`#guard_msgs`) |
| `../Ref.lean` | imports Basic, Scheme, Count, Lemmas |
| `../Images.lean`, `../Submission.lean` | the four images (copied from `work/py/out/Images.lean`, namespace `SigGolfCandidate.Images`) and `SigGolfCandidate.submission : SigGolf.Submission` with `submission_admissible` (`decide +kernel`) |

Trust: no `sorry`, `native_decide` or `bv_decide`. The only axioms are `propext`,
`Classical.choice` and `Quot.sound` (see `Axioms.lean`).

## Conventions

* `Val := List Byte`. It holds every 16-byte value: secrets, chain values, nodes, roots, `rho`.
  Byte `i` of `x : Bytes n = BitVec (8n)` is bits `8i..8i+7`, which is `SigGolf.bytes` and the
  RISC-V memory order. `toList x` gives the bytes and `ofList n l` builds the value from them
  (little endian).
* Numbers (`idx`, `N`, `tau`, `e`, counters, digits) are `Nat`. Shifts are written as
  `/ 2^k` and masks as `% 2^k`.
* **Loops.** Every loop is either a `List.foldlM` over `List.range n` (`0..n-1`) or
  `List.range' a n` (`a..a+n-1`), or a structural recursion on a fuel or layer count. A
  recursion is used when the loop can stop early (searches, layers). An accumulated list grows
  at the end (`acc ++ [v]`), so after `j` iterations it holds exactly the first `j` results.
  Bookkeeping that makes no queries (captures, path siblings) is done where the bytecode does
  it.
* The layer recursions `signLayers` / `verifyLayers` take `lay + 1` and process layer `lay`
  first, then call themselves on `lay`. Called with `nLayers = 7`, they run layers 6, 5, ..., 0.

### Parameters
`nChains = 42`, `target = 170`, `nLayers = 7`, `totalH = 34`, `ftsA = 10`, `ftsTrees = 14`,
`aMax = cMax = 2^20`, `sigBytes = 7756`, `height lay = if lay = 6 then 4 else 5`,
`shiftBelow lay = sum_{j>lay} h_j` (table `[29,24,19,14,9,4,0]`, lemma `shiftBelow_values`),
`route idx lay : Nat × Nat := (idx / 2^s % 2^h, idx / 2^(s+h))`, which is `(e, tau)`.

### Tweak, padding, hashing
```lean
def tweak (t lay tau p j : Nat) : List Byte
  -- [1, t, lay, tau/2^32] ++ le32 p ++ le32 (tau % 2^32) ++ le32 j
  -- (word0 = 1 | t<<8 | lay<<16 | (tau>>32)<<24 | p<<32, word1 = tau mod 2^32 | j<<32)
def P : List Byte := zeros 16
def thInput (tw payload : List Byte) : List Byte := tw ++ P ++ payload
def padBlocks (len : Nat) : Nat := (len + 63) / 64 - 1      -- n (the query has n+1 blocks)
def padTo64 (x : List Byte) : List Byte                     -- x ++ 0^(64(n+1) - |x|)
def pad64 (x : List Byte) : Query := ⟨padBlocks x.length, ofList _ (padTo64 x)⟩
def H (x : List Byte) : OracleComp HashSpec (BitVec 256) := HashSpec.query (pad64 x)
def hash16 (x : List Byte) : OracleComp HashSpec Val        -- answerBytes 16 <$> H x
def th (tw payload : List Byte) : OracleComp HashSpec Val := hash16 (thInput tw payload)
```

### Digest, split, decoding
```lean
def digest (rho m : List Byte) : OracleComp HashSpec Nat   -- (H (digestInput rho m)).toNat % 2^184
def idxOf (N : Nat) : Nat := N % 2^34
def uOf (N k : Nat) : Nat := N / 2^(34 + 10k) % 2^10
def admissible (N : Nat) : Bool := uOf N 14 == 0
def digitsOfWord (d : Nat) : List Nat                      -- [d / 8^r % 8 | r = 0..20]
def decodeDigits (v : Val) : Option (List Nat)
  -- d0 = leNat v[0..8), d1 = leNat v[8..16); none if d0 ≥ 2^63 or d1 ≥ 2^63;
  -- x = digitsOfWord d0 ++ digitsOfWord d1; some x iff x.sum = 170
```

### Tree building (sign, keygen; `Scheme.lean`)
```lean
abbrev NodeFmt := Nat → Nat → Val → Val → List Byte       -- node lam j l r
def buildLevel (node : NodeFmt) (lam : Nat) (level : List Val) : OracleComp HashSpec (List Val)
    -- foldlM over range (|level|/2): hash16 (node lam j level[2j] level[2j+1])
def levelStep (node : NodeFmt) (cap : Nat) (st : List Val × List Val) (lam : Nat)
    : OracleComp HashSpec (List Val × List Val)             -- path += level[(cap>>(lam-1)) xor 1]; buildLevel
def buildLevels (node : NodeFmt) (cap h : Nat) (leaves : List Val) : OracleComp HashSpec (Val × List Val)
    -- foldlM (levelStep node cap) over range' 1 h from (leaves, []); (root, path)
def buildChain (S : List Byte) (lay tau e i x : Nat) : OracleComp HashSpec (Val × Val)
    -- prf, then foldlM over range' 1 7 (steps mu); (end, value at position x)
def buildLeaf (S : List Byte) (lay tau e : Nat) (x : List Nat) : OracleComp HashSpec (Val × List Val)
    -- foldlM over range 42 (buildChain .. (x.getD i 0)), then leaf hash; (leaf, captured values)
def buildLeaves (S : List Byte) (lay tau h cap : Nat) (x : List Nat) : OracleComp HashSpec (List Val × List Val)
    -- foldlM over range (2^h) of buildLeaf; captured values of leaf cap
def buildTree (S : List Byte) (lay tau h cap : Nat) (x : List Nat)
    : OracleComp HashSpec (Val × List Val × List Val)       -- (root, vals, path) = ref.build_tree
```

### Counting (`Count.lean`)
```lean
def countImpl (wt : Query → Nat) : QueryImpl HashSpec (StateT Nat (OracleComp HashSpec))
def countWith (wt : Query → Nat) (oa : OracleComp HashSpec α) : OracleComp HashSpec (α × Nat)
def countCalls  (oa) := countWith (fun _ => 1) oa      -- number of queries
def countBlocks (oa) := countWith Query.blocks oa      -- number of compressions
theorem countImpl_run : (simulateQ (countImpl wt) oa).run n = (fun p => (p.1, n + p.2)) <$> countWith wt oa
@[simp] countWith_pure  : countWith wt (pure a) = pure (a, 0)
theorem countWith_bind  : countWith wt (oa >>= f) =
    countWith wt oa >>= fun p => (fun r => (r.1, p.2 + r.2)) <$> countWith wt (f p.1)
@[simp] countWith_query : countWith wt (liftM (HashSpec.query q)) = (fun a => (a, wt q)) <$> liftM (HashSpec.query q)
@[simp] countWith_H     : countWith wt (H x) = (fun a => (a, wt (pad64 x))) <$> H x
@[simp] fst_countWith   : Prod.fst <$> countWith wt oa = oa
-- countCalls_pure / _bind / _query / _H, fst_countCalls,
theorem evalWith_countCalls_fst : (evalWithAnswerFn hash (countCalls oa)).1 = evalWithAnswerFn hash oa
```

## Validation (`Test.lean`, built with the library in about 12 s)

`tools/ref_vectors.py` runs `ref.py` with a toy oracle. With `x` = the padded query as a LE
number, `nb` = the number of blocks and `M = 2^521 - 1`, it computes
`z = x mod M; z = (z^2 + 0x9E3779B97F4A7C15) mod M; z = (z^2 + nb) mod M` and answers
`z mod 2^256`. Lean has the same function (`Test.toyHash`). Each check compares three things:
the result, the number of calls, and an order-sensitive fingerprint
`sum_i (i+1) * answer_i mod 2^256` of the whole query sequence. The checks cover:

* `keygenList` (10,815 calls; `countCalls` gives 10,815 and `countBlocks` gives 11,135), and
  `keygenRef` through the organizer's `evalWithAnswerFn`;
* the **full `signRef`** (121,400 calls; it runs in a few seconds), `searchDigest`,
  `searchCounter`;
* one `buildTree` with capture (lay 3, tau 5, e 17), and `buildFtsTree` with height 4;
* `decodeDigits` on 48 vectors: random, valid ones, and ones with pad bit 63 or 127 set;
* `toWitness` / `fromWitness` / `expandRef` / `unexpandRef` against `ref.to_witness`;
* `verifyRef` on the honest witness (true, 1,072 calls). It is also checked on corrupted
  witnesses: a chain value, a sibling, a counter, a counter ≥ 2^20 (false with 0 queries), rho,
  a FORS secret, and a wrong pk. `verifySigRef` is checked on the signature.

To regenerate the vectors: `python3 tools/ref_vectors.py`, then `lake build`.
